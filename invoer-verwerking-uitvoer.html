Wat is Invoer - Verwerking - Uitvoer?

Een computer krijgt voortdurend gegevens binnen. Deze gegevens worden verwerkt door de computer en daarna komt er een resultaat uit. Dit noemen we het invoer-verwerking-uitvoerproces.

In het Engels wordt dit vaak Input - Process - Output genoemd, oftewel IPO.

Je kunt het zien als een stappenplan: eerst krijgt de computer informatie binnen, daarna verwerkt de computer deze informatie en uiteindelijk geeft de computer een resultaat.

De drie stappen

1. Invoer

Invoer is de informatie die je aan een computer geeft. Dit kan bijvoorbeeld door een toetsenbord, muis, microfoon, camera of touchscreen.

2. Verwerking

Tijdens de verwerking doet de computer iets met de ingevoerde gegevens. De processor voert bijvoorbeeld berekeningen en opdrachten uit.

3. Uitvoer

Uitvoer is het resultaat dat de computer geeft. Dit kan bijvoorbeeld op een beeldscherm, via een luidspreker of met een printer worden weergegeven.

Een voorbeeld uit het dagelijks leven

Stel dat je een zoekopdracht uitvoert op Google.

Invoer: je typt een zoekterm in op het toetsenbord.

Verwerking: de computer en de zoekmachine verwerken je zoekopdracht en zoeken naar passende informatie.

Uitvoer: de zoekresultaten verschijnen op je scherm.

Op deze manier kun je het invoer-verwerking-uitvoerproces herkennen in veel verschillende situaties waarbij je een computer gebruikt.
